# unkan

iOSアプリ「運行管理者(貨物) 合格予測（非公式）」の公開情報（サポート・プライバシーポリシー・利用規約）を管理するリポジトリです。GitHub Pages（`main` ブランチの `/docs`）で公開しています。

- サポート: https://taaaaho.github.io/unkan/
- プライバシーポリシー: https://taaaaho.github.io/unkan/privacy.html
- 利用規約: https://taaaaho.github.io/unkan/terms.html

ページの文言は `scripts/build_pages.py` で管理しています。編集後に `python3 scripts/build_pages.py` を実行してください。

本アプリは個人開発の非公式アプリであり、公益財団法人運行管理者試験センター・国土交通省その他の団体とは提携・協力・監修関係はありません。

ソースコードは非公開リポジトリ（`unkan-code`）で管理しています。
